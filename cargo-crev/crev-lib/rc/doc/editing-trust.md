# 信頼プルーフの作成 {#creating-trust-proof}

信頼プルーフ (Trust Proof) は、`crev` システムの中の別の主体の動機、能力、基準に対する
あなたの信頼を記録します。

（distrust を除く）すべての信頼レベルは肯定的なものです。`none` レベルは、
互いを知らない 2 人のユーザの間のデフォルトとみなされます。
それより上は「何もないよりは上」という意味です。

## 不信について {#on-distrust}

不信 (distrust) は、唯一の懲罰的な信頼レベルです。その目的は、悪意のある、
あるいはほかの形で有害な登録を示し、ほかのユーザに警告することです。
軽々しく使うべきではなく、ほかの人の WoT からその相手を除外しようとする理由を
説明するコメントを必ず付けてください。それについての議論へのリンクを含めてもかまいません。

不信プルーフを作る前に、そのユーザに連絡して誤った行いを正してもらうよう試みること、
さらに/またはそれについてほかの人の意見を聞くことをおすすめします。

`distrust` レベルを使う理由の例:

* ユーザが、悪意のある/壊れた/品質の低いクレートに対して、おそらく故意に
  肯定的なレビューを作っている。
* ユーザが不注意に `thoroughness` や `understanding` のレベルを水増ししていて、
  ほかの人を誤解させるおそれがある。
* ユーザが、おそらく故意に、問題のあるほかのユーザを高い信頼に置いたまま、
  それを下げたり削除したりすることを拒んでいる。
* ユーザが不当な不信プルーフを作っている。

不信レベルを使う理由に *ならない* ものの例:

* ユーザが `thoroughness` や `understanding` の低いレビューを作っている。
  自己申告の `thoroughness` と `understanding` のレベルが正直である限り、
  そうしたレビューもコミュニティにとって有益です。使いたくなければ、
  `--thoroughness X` や `--understanding X` フラグでそれらを除外するのは
  ほかのユーザの役目です。
* ユーザのレビューの基準が、私の高い品質基準に合わない。これも、コミュニティを
  危険にさらさない範囲であれば、レビューをうまくこなすと信頼できない相手や、
  ほかのユーザの品質や基準を判断できると信頼できない相手に、低い信頼レベルを
  割り当てるのはほかのユーザの責任です。そのような相手の信頼レベルを下げ、
  さらにその相手をより高いレベルで推移的にあなたの WoT に持ち込むかもしれない
  ほかの相手の信頼レベルも下げてください。特定の信頼レベルより下の相手からの
  レビューを除外するには、`--level X` フラグを使ってください。

## 責任 {#responsibility}

`crev` は、あなたが信頼する主体からの害に直接あなたをさらすことはありませんが、
信頼できない主体をあなたの信頼の網 (Web of Trust) に加えると、全体的なセキュリティ、
さらに/または評判が下がるかもしれません。

一方で、信頼の網の中に信頼できる主体が多いほど、その届く範囲は広がり、
見つけられるデータも多くなります。

あなたのプルーフは暗号学的に署名され、エコシステムの中で流通します。
`crev` システムを使うことに明示的にも暗黙的にも法的な責任は伴いませんが、
ほかの人はほぼ確実に、それを使ってあなたやあなたのほかの仕事などを評価するでしょう。

プルーフを作って公開することで、あなたはほかの人がそれを自由に使うことに
暗黙のうちに同意したことになります。

## データフィールド {#data-fields}

- `trust` - 信頼レベル。とりうる値:
  - `high` - 「ほとんどの実用上の目的について、このユーザは私と同じかそれ以上に
     良い仕事をすると信頼している」。例:「仕事用の私の ID」、「よく知られた評判の良い専門家」、
    「同じチームの従業員」
  - `medium` - 「このユーザを信頼しているが、自分自身ほどではない。レビューの基準は
    問題ないかもしれないが、私の基準よりは低い」
  - `low` - 「この主体を信頼することには多少の留保があるが、それでもその判断には
    ある程度の価値があると考えている」
  - `none` - 「この主体を知らない、または信頼していない」。以前に発行した信頼プルーフの
    信頼（または不信）を取り消すため、さらに/または単にユーザの存在を知らせるために使う
  - `distrust` - 「このユーザは悪意がある/有害だと思う」
- `comment` - この信頼関係についての人間が読める情報（たとえば、
  これらの主体は誰か、なぜ信頼するのか）
- `override` - 対象の Id について、信頼を上書きする（無視する）Id のリスト

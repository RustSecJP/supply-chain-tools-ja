# 用語集 {#glossary}

以下は、`crev` と `cargo-crev` でよく使われる用語の用語集です

### *アドバイザリ* (*Advisory*) {#advisory}

*レビュー* の省略可能な一部で、そのパッケージのバージョンで修正された重大な問題を
告知し、ほかのユーザにアップグレードを勧めるものです。

注目すべき点として、*アドバイザリ* は、ある *VersionRange* の中のそれより前の
すべてのバージョンにその問題があることを暗に示します。

### *CrevId* {#crevid}

`crev` のデフォルトの（そして今のところ唯一サポートされている）アイデンティティの種類です。
*プルーフ* に署名するのに使う、自分で生成するアイデンティティです。

内部的にはただの鍵ペアで、公開鍵が公開 ID として使われ、秘密鍵はローカルに
保存されてパスフレーズで暗号化されます。

### *イシュー* (*Issue*) {#issue}

*レビュー* の省略可能な一部で、あるパッケージのバージョンにある重大な問題を
告知するものです。

*アドバイザリ* とよく似ています。ふつうは *アドバイザリ* を選ぶほうがよいですが、
問題の解決策がまだない場合は別です。

### *レベル* (*Level*) {#level}

レベルは、`crev` でものごとを評価するのによく使われます。ふつうは次の 4 つの値の
どれかをとります:

- high
- medium
- low
- none

### *プルーフ* (*Proof*) {#proof}

ある事実を証明する YAML ドキュメントです。今のところサポートされている *プルーフ* の
種類は次のとおりです:

- *信頼プルーフ* (*Trust Proof*) - プルーフの作者が別のアイデンティティを信頼できると
  みなしていることを証明するもの
- *パッケージレビュープルーフ* (*Package Review Proof*) - 特定のパッケージ/ライブラリの
  コードレビューの結果を記述するもの

今後、さらに多くの種類のプルーフが導入されるかもしれません。

### *プルーフリポジトリ* (*Proof Repository*) {#proof-repository}

*プルーフ* を保存するのに使う `git` リポジトリです。`git` リポジトリと同じように、
*プルーフリポジトリ* はローカルにも公開にもできます。

### *レビュー* (*Review*) {#review}

*パッケージレビュープルーフ* の略です。特定のパッケージのソースコードの
レビューの結果を記述したドキュメントです。

### *信頼集合* (*Trust Set*) {#trust-set}

与えられたルートアイデンティティから *信頼の網* (*Web of Trust*) をたどった結果で、
直接または推移的に信頼できるとみなされる、ほかのすべてのアイデンティティの集合を
計算したものです。

入門としては [信頼のドキュメントのモジュール](trust.html) を見てください。

### *信頼の網* (*Web of Trust*, *WoT*) {#web-of-trust-wot}

アイデンティティをノードとし、それらの間の信頼関係を辺とするグラフです。

利用できるすべての *信頼プルーフ* からその場で作られ、与えられたアイデンティティの
*信頼集合* を計算するのに使われます。

入門としては [信頼のドキュメントのモジュール](trust.html) を見てください。

### *バージョン範囲* (*Version Range*) {#version-range}

`crev` での、バージョンの範囲を簡単に指定する方法です。

次の値をとれます:

- `all` - すべてのバージョン
- `major` - メジャーリリース（例: 2.x.y）
- `minor` - メジャーリリース（例: 2.1.x）

バージョン 1.2.3 の *レビュー* で報告された *アドバイザリ* は、次の間の
すべてのバージョンに影響します:

- *バージョン範囲* の値 `all` で報告された場合は `0.0.0` から `1.2.3` まで
- *バージョン範囲* の値 `major` で報告された場合は `1.0.0` から `1.2.3` まで
- *バージョン範囲* の値 `minor` で報告された場合は `1.2.0` から `1.2.3` まで
